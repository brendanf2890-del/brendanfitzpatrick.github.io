# Inventory Monetization Model (VBA)

A self-building Excel/VBA model for a bank-side **inventory monetization**
(borrowing-base / repo-style) deal against a refiner's physical tank stock.
The bank advances cash against the net standard volume (NSV) of inventory,
marked daily at index-linked prices net of an advance rate and a hedge-back
basis. The whole workbook is generated by code — there is no template to ship.

## Files
- `InventoryMonetizationModel.bas` — the complete VBA module. Import it and run.

## How to run
1. In Excel press **Alt+F11** → **Insert ▸ Module** → paste the whole `.bas`.
2. Run **`BuildModel`** to construct the workbook from scratch.
3. Each new flow date, run **`RollNewDay`**: it freezes the current live row to
   values (settled history) and opens a fresh live row that re-pulls the Latest
   Inventory Report and the live price build-up.

## What it builds (5 tabs)
- **Latest Inventory Report** — daily tank gauge → VCF → GSV → NSV per tank
  (60 °F correction, BS&W deduction), grouped into 12 product groups.
- **Daily Ledger** — one row per flow date. 30 settled history rows are
  hard-coded; the live row pulls End NSV per group via `SUMIF` on the report's
  Grp Key, with Begin = prior day's End. Settlement dates are
  `Delivered = WORKDAY(Flow,1)`, `Invoiced = WORKDAY(Flow,2)`,
  `Paid = WORKDAY(Flow,3)`, holiday-aware (Fri/Sat/Sun batch to Tue/Wed).
- **Daily Pricing** — Net settlement `$/bbl` per group. A Live Price Build-Up
  block drives the live row: `Net = (Index × Conv + Diff) × Advance Rate + Total HB`.
  Pricing stays live regardless of the invoice lag (lag is a cash item only).
- **Exposure** — `Total Exposure = Σ (End NSV × Net Settlement)` marked at live
  prices; `Daily Settlement` = day-over-day change (the true-up), with
  green/red conditional formatting.
- **Notes & Key** — methodology, settlement-timing notes, NYMEX/US holiday
  list (named range `Holidays`), and the color key.

## Conventions
- **Color key:** blue = input, black = calc, green = cross-sheet link;
  navy/yellow = headers. The live row is shaded green.
- **Named ranges:** `ValDate` (valuation date) and `Holidays` (WORKDAY calendar).
- Figures are **synthetic** (seeded RNG, reproducible) for demonstration — wire
  the Latest Inventory Report and the price build-up to real feeds for live use.
